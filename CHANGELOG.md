# Changelog

## 1.0.0 — 2026-11-10

- First public MIT release of the Windows Claude Code notification plugin.
- Answer previews, system sound and per-session three-second Stop-event coalescing.
- Persistent switch, notification test and built-in usage help.
- Standard marketplace, agent runbook, llms.txt and complete Windows ZIP installer.
- Handles spaced/non-ASCII paths and respects CLAUDE_CONFIG_DIR.
- Restricts transcript fallback to the current session; logs omit private text and paths.
- Explicit release packaging with SHA-256 checksums.
